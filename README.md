# Financial Ecosystem & Risk Analysis Dashboard

An end-to-end data analytics mini project assessing financial transaction performance, customer demographic profiling, and risk/fraud intelligence using **Excel** for data pre-processing and **Power BI** for interactive visualization.

---

## 📌 Project Overview
This project analyzes a dataset of **5,000 customer transaction records** across 50 multi-faceted attributes. The goal is to build an interactive business intelligence solution that addresses executive performance, portfolio health, and anti-money laundering (AML) risk assessment.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data profiling, missing value checks (`COUNTBLANK`), standardization, and calculated helper columns (`Net_Cash_Flow`, `Risk_Level`, `Txn_Year_Month`).
* **Power BI Desktop:** Data modeling, custom DAX measures, and multi-page interactive dashboard creation.
* **GitHub:** Version control and project repository management.
